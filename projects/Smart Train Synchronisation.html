Smart Train Synchronisation (SCADA Simulation)

A Python-based supervisory control and data acquisition simulation designed to demonstrate monitoring, system status visualisation, and control of a public transport system.

Python Tkinter SCADA GUI Development
Explore Project ↓

01 / PROJECT OVERVIEW

This project involved developing a Smart Public Transport SCADA simulation using Python and Tkinter. The system demonstrates how a graphical interface can be used to represent transport operations, display system states, and provide a centralised monitoring environment.

The project focuses on the software concepts behind industrial monitoring systems, including visualisation, control interfaces, status indicators, and event handling.

02 / PROJECT OBJECTIVES

01. System Monitoring

Present transport system information through a centralised graphical interface.

02. Visualisation

Use graphical elements and status indicators to make system states easier to understand.

03. User Interaction

Develop interface components that allow users to interact with the simulated system.
