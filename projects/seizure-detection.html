EEG-Based Seizure Detection & Alert System

A proof-of-concept engineering project exploring how EEG classification software can communicate with a Raspberry Pi to trigger an external alert system.

Python Machine Learning Raspberry Pi 5 TCP Communication Hardware Integration
Explore Project ↓

01. Project Overview

This project investigates a proof of concept for detecting potential seizure events from EEG data and communicating an alert to external hardware.

When seizure activity is identified, the detection software sends a “SEIZURE” message to the Raspberry Pi over TCP. The Pi activates a buzzer and provides a three-minute acknowledgement period. If no acknowledgement is received, it continues the alarm and is designed to send an emergency email, share GPS coordinates, and contact emergency services.

Project objective

The objective of this project was to investigate the feasibility of a wearable EEG headband for the early detection of temporal epileptic seizures. The system was designed to monitor electrical brain activity near the temporal region, use a machine-learning model trained on epilepsy EEG data to identify seizure-related patterns, and trigger an automated alert process when a potential seizure is detected. By integrating wearable electrodes, EEG analysis software, and a Raspberry Pi-based alarm and notification system, the project aimed to improve patient safety and monitoring while establishing a proof of concept for future real-time clinical application.

02. Problem & Objectives

Issue:

The issue faced by individuals with epilepsy is the unpredictability of seizures, which can occur without warning, leading to potential injuries, loss of awareness, and heightened risk of Sudden Unexpected Death in Epilepsy (SUDEP), especially when alone. Many are not aware when a seizure takes place, particularly during sleep, making self-reporting unreliable. Current wearable systems detect seizures through indirect signals like movement and heart rate, but they may yield false alarms and react only after a seizure starts. While EEG is the gold standard for monitoring brain activity, its high cost and complexity limit its use to hospitals. This situation highlights the necessity for a portable device capable of continuously monitoring EEG, identifying seizure patterns, and notifying both the individual and caregivers.

Objectives:

  • Explore EEG-based seizure classification.
  • Process classification results using Python.
  • Transmit alert messages over a TCP connection.
  • Receive messages using a Raspberry Pi 5.
  • Trigger a buzzer through a GPIO output.
  • Investigate possible caregiver notification features.

03. System Architecture

The prototype separates the classification workflow from the physical alert hardware. This allows the communication and alert functions to be tested independently.

01. EEG Processing

EEG data and the Python classification workflow are handled on a Windows laptop.

02. TCP Communication

The laptop sends an alert message to the Raspberry Pi over a network connection.

03. Hardware Alert

The Raspberry Pi receives the message and controls a buzzer through a GPIO output.

Hardware: BioRadio EEG system, Windows laptop, Raspberry Pi 5 and buzzer.

Software: Python, Random Forest classification workflow and TCP socket communication.

05. Engineering Challenges

EEG data integration

The BioRadio data workflow presented an integration challenge because the manufacturer's Windows application was used for EEG acquisition, while the Raspberry Pi could not directly access the required real-time data through the available interface.

Software-to-hardware communication

The classification workflow and physical alert hardware operated on separate devices. TCP communication provided a way to transmit an alert message from the laptop to the Raspberry Pi.

Alert behaviour

The alert logic was developed to demonstrate how an event could trigger a buzzer and how a physical button could be incorporated into the prototype. The implemented timing and button behaviour should be documented alongside the actual test results.
